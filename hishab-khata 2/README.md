# হিসাব খাতা

React (Vite) + Vercel Serverless Functions + PostgreSQL। প্রতিটি ব্যবহারকারীর নিজস্ব অ্যাকাউন্ট ও আলাদা ডেটা।

## Vercel-এ চালু করার ধাপ

### ১. ডাটাবেস বানান
1. [neon.tech](https://neon.tech) এ বিনামূল্যে অ্যাকাউন্ট খুলে একটি প্রজেক্ট বানান (অথবা Vercel Dashboard → Storage → Neon)।
2. কানেকশন স্ট্রিং কপি করুন। এটা দেখতে `postgresql://...?sslmode=require` এর মতো।
3. Neon-এর **SQL Editor** খুলে `db/schema.sql` ফাইলের পুরো লেখা পেস্ট করে **Run** চাপুন। এতে সব টেবিল তৈরি হবে।

### ২. কোড আপলোড করুন
1. এই ফোল্ডারটি একটি GitHub রিপোজিটরিতে পুশ করুন।
2. [vercel.com](https://vercel.com) → **Add New → Project** → রিপোজিটরিটি Import করুন। Framework নিজে থেকেই **Vite** ধরা পড়বে।
3. **Environment Variables**-এ যোগ করুন: `DATABASE_URL` = আপনার কানেকশন স্ট্রিং।
4. **Deploy** চাপুন। হয়ে গেলে লিংক খুলে সাইন আপ করুন।

## নিজের কম্পিউটারে চালাতে (ঐচ্ছিক)
```bash
npm install
cp .env.example .env      # DATABASE_URL বসান
npm run migrate           # টেবিল তৈরি
npx vercel dev            # http://localhost:3000
```


## পাসওয়ার্ড রিসেট (Gmail দিয়ে ইমেইল পাঠানো)

1. রিসেট মেইল পাঠানোর জন্য শুধু এই কাজে একটা **নতুন Gmail অ্যাকাউন্ট** খুলুন (নিজের মূল Gmail নয়)।
2. সেই Gmail-এ **২-ধাপ যাচাই (2-Step Verification)** চালু করুন: myaccount.google.com → Security।
3. https://myaccount.google.com/apppasswords এ গিয়ে নাম দিন "hishab-khata", **Create** চাপুন। ১৬ অক্ষরের একটা পাসওয়ার্ড দেখাবে। স্পেস বাদ দিয়ে কপি করুন।
4. Vercel → প্রজেক্ট → Settings → Environment Variables-এ তিনটি যোগ করুন:
   - `GMAIL_USER` = নতুন Gmail ঠিকানা
   - `GMAIL_APP_PASSWORD` = ১৬ অক্ষরের পাসওয়ার্ড (স্পেস ছাড়া)
   - `APP_URL` = আপনার অ্যাপের ঠিকানা, যেমন `https://hishab-khata.vercel.app` (শেষে `/` নেই)
5. Neon SQL Editor-এ `db/schema.sql` আবার পেস্ট করে চালান (নতুন টেবিল যোগ হবে, পুরনোগুলো যেমন আছে তেমনই থাকবে)।
6. Vercel-এ আবার **Redeploy** করুন।

লোকালে `GMAIL_USER` না দিলে রিসেট লিংক টার্মিনালে ছাপা হবে।

## অ্যাডমিন প্যানেল ও নামাজের অ্যালার্ম

1. Vercel → Settings → Environment Variables-এ যোগ করুন:
   - `ADMIN_USERNAME` = গোপন ইউজারনেম (কমপক্ষে ৩ অক্ষর, `@` থাকবে না)
   - `ADMIN_PASSWORD` = শুরুর পাসওয়ার্ড (কমপক্ষে ৮ অক্ষর)
   - `ADMIN_EMAIL` = যে ইমেইলে ওটিপি যাবে
2. Redeploy করুন।
3. সাধারণ লগইন পাতার "ইমেইল" ঘরে ইউজারনেম লিখে পাসওয়ার্ড দিলে অ্যাডমিন প্যানেল খুলবে। ব্যবহারকারীদের কাছে এর কোনো লিংক বা ইঙ্গিত নেই।
4. প্যানেলে ঢুকেই **পাসওয়ার্ড বদলে** নিন। বদলানোর পর Vercel-এর `ADMIN_PASSWORD` আর কাজ করে না, শুধু ডাটাবেসের পাসওয়ার্ড চলে।
5. পাসওয়ার্ড ভুলে গেলে: লগইন পাতায় ইউজারনেম লিখে "পাসওয়ার্ড ভুলে গেছেন?" চাপুন। ইমেইলে ৬ সংখ্যার ওটিপি যাবে (১০ মিনিট চলে, ৫ বার ভুল করলে বাতিল)।
6. প্যানেলে নামাজের সময়, চালু/বন্ধ ও স্নুজের মিনিট ঠিক করুন। ডিফল্ট সময়গুলো শুধু নমুনা, নিজের এলাকার সময় বসিয়ে নিন।

অ্যালার্ম ব্যবহারকারীর ফোনের সময় ধরে বাজে এবং অ্যাপটি খোলা থাকলে কাজ করে।

## নিরাপত্তা ও ডেটা আলাদা রাখার ব্যবস্থা
- পাসওয়ার্ড scrypt দিয়ে হ্যাশ করে রাখা হয়, আসল পাসওয়ার্ড কোথাও জমা থাকে না।
- লগইনের পর HttpOnly, Secure, SameSite কুকিতে সেশন থাকে। সার্ভারে শুধু সেশন টোকেনের হ্যাশ জমা থাকে।
- প্রতিটি অনুরোধে সার্ভার সেশন থেকে ব্যবহারকারী চিনে নেয়, আর সব কুয়েরিতে `user_id` শর্ত থাকে। তাই একজন আরেকজনের ডেটা দেখতে বা মুছতে পারে না।
- একই ইমেইলে ১৫ মিনিটে ৮ বার ভুল পাসওয়ার্ড দিলে সাময়িকভাবে লগইন বন্ধ হয়।
- রিসেট লিংক এক ঘণ্টা চলে, একবার ব্যবহার করা যায়। পাসওয়ার্ড বদলালে সব পুরনো লগইন বন্ধ হয়।
- অন্য সাইট থেকে আসা লেখার অনুরোধ (CSRF) Origin যাচাই করে আটকানো হয়।
- সব টাকার অঙ্ক সার্ভারে যাচাই হয়। পরিশোধ কখনো বকেয়ার বেশি হতে পারে না।

## ফোল্ডার

- `src/` — React অ্যাপ
- `db/schema.sql` — ডাটাবেস টেবিল
